# Repository Documentation

## `snakeandladder.py`

This script simulates a classic board game of Snakes and Ladders. The game is played on a rectangular board with numbered squares, where players roll dice to move forward. However, some squares have snakes or ladders that can either hinder or help the player's progress. The goal is to reach the final square (100) first. The script allows users to play the game by inputting their name and starting position. It then simulates the game, displaying the current position, roll of the dice, and any movement due to snakes or ladders. The game ends when a player reaches the final square, and the winner is announced.

## `main.py`

This script serves as the entry point for the Snakes and Ladders game. It initializes the game environment, prompts users for input, and controls the flow of the game. When run, it displays a menu with options to start a new game or quit. Based on user input, it calls the corresponding functions to begin the game. The script also handles any errors that may occur during gameplay.
