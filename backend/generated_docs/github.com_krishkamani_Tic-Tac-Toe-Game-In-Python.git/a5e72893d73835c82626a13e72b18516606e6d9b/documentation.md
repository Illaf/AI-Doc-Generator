# Repository Documentation

## `Tic_Tac_Toe_Game.py`

This script is a simple implementation of the classic game Tic Tac Toe. It allows two players to take turns marking squares on a 3x3 grid. The game continues until one player has three in a row, column, or diagonal. The script includes functions for restarting the game and disabling buttons.

## `Button.py`

This file contains classes that represent buttons in the Tic Tac Toe game. Each button object has methods to disable itself when clicked and to trigger a click event. These classes are used throughout the game to create interactive elements on the grid. The script provides a basic framework for handling user input.

## `restartbutton.py`

This file contains functions related to restarting the Tic Tac Toe game. It includes a function to reset the game state, clear the board, and update the display. The purpose of this script is to provide a clean start for new games, allowing players to begin again from scratch.
