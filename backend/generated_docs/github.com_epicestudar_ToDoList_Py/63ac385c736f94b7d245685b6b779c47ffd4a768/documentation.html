Repository Documentation

Interface Grafica\ToDoList.py

DOCS: This script is used to create a graphical user interface (GUI) for managing a To-Do list. It provides methods for visualizing data, adding new tasks, marking completed tasks, deleting tasks, and clearing placeholders. Think of it like a digital sticky note where you can write down tasks and check them off as you complete them. This script is the brain behind that sticky note, allowing users to interact with it through various GUI elements.

Terminal\ToDoList.py

DOCS: This script provides methods for managing a To-Do list from the command line. It allows users to add new tasks, list existing tasks, delete tasks, edit tasks, and mark completed tasks. Imagine you're using a voice assistant like Siri or Alexa, but instead of speaking commands, you type them into your computer. That's what this script is like – it takes in text-based commands and executes the corresponding actions on your To-Do list.
