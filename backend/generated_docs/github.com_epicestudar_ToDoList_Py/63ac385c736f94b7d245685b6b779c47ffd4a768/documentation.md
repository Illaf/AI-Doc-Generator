# Repository Documentation

## `Interface Grafica\ToDoList.py`

DOCS: This script is responsible for creating a graphical user interface (GUI) for managing to-do lists. It provides methods for visualizing data, adding new tasks, marking completed tasks, deleting tasks, and clearing placeholders. The GUI allows users to interact with the application in a more intuitive way.

## `Terminal\ToDoList.py`

DOCS: This script is used to manage to-do lists through a text-based interface. It provides methods for adding new tasks, listing existing tasks, deleting tasks, editing tasks, and marking completed tasks. The script uses command-line inputs to allow users to interact with the application from the terminal or command prompt.
